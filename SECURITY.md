# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting for this repository when it is enabled. If
that channel is unavailable, contact the repository owner
[@ricardoakinaga-dev](https://github.com/ricardoakinaga-dev) privately through
GitHub and include only the minimum synthetic reproduction needed to triage.

Do not send passwords, private keys, bearer tokens, real veterinary data, or
other live secrets in a report.

## Scope and response

The maintainer will acknowledge a report when received, assess impact and
reproduction, and coordinate remediation or disclosure timing. This document
does not promise a response time or imply that local CI is a production
security certification.
