# ADR 003 — Policy Decision Point separado

**Status:** accepted for implementation; políticas de produção ainda exigem homologação humana.

O PDP recebe ator, role, organização, unidade, workspace, recurso, finalidade, operação, risco, tempo, revisão de policy, sessão e classe de dados. O resultado inclui revisão e obrigações auditáveis.

A autorização de rota, tool e repository deve consumir o mesmo PDP. RLS é defesa adicional, não substituto da decisão de negócio.
